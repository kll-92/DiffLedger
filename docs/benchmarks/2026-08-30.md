# CLI baseline benchmark — 2026-08-30

This is a reproducible engineering baseline, not a cross-tool performance
claim. Run `npm run benchmark` to repeat it on the current machine.

## Scenario

- Temporary real Git repository
- 200 tracked TypeScript files modified
- Working tree compared with `HEAD`
- Change classification, risk assessment, Receipt JSON generation and SHA-256
- No Evidence Checks, so the result measures DiffLedger/Git overhead rather
  than project test time
- One warm-up followed by five measured runs

## Result

```json
{
  "scenario": "200 modified TypeScript files, no Evidence Checks",
  "runs": 5,
  "medianMs": 198,
  "minMs": 187,
  "maxMs": 212,
  "node": "v24.16.0",
  "platform": "darwin/arm64"
}
```

Results vary with Git version, filesystem cache, CPU, and storage. Future
baselines should preserve the scenario and record environment changes.
